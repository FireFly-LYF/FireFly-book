# 业务读公平对比（交替先后） 20260910-125902

双端 **WSL**；每接口两侧预热 3s，相邻接口交替「谁先正式压」，避免整边预热偏差。

## 环境与压测参数（归档）

| 项 | 值 |
|----|-----|
| 宿主 | WSL2 |
| CPU（`nproc`） | **4** vCPU |
| 内存（`free`） | **~7.8 GiB** |
| 宿主 CPU 型号 | Intel Core i7-14650HX（WSL 配额 4 核） |
| wrk 正式 | **`-t4 -c50 -d20s`**（未加 `--latency`，无 P99） |
| wrk 预热 | **`-t2 -c10 -d3s`**（每侧、每接口） |
| 策略 | 两侧预热 → 正式压测；相邻接口交替先后（Go 先 / Java 先） |
| Go | `bench/config/gateway-wsl-compare.yaml`（关限流/熔断/Redis） |
| Java | SCG `:8088`，无限流 |
| USER_ID / NOTE_ID | 15 / 98 |
| 写压测 | 未包含 |

说明：Latency **Max** = wrk 样本最大值；**Socket timeout** ≈ 未在默认超时内完成的请求数。要 P99 需重跑并加 `wrk --latency`。

## 结果

### 吞吐（Requests/sec）

| 接口 | 先后 | Go | Java | Go 相对 Java |
|------|------|-----|------|--------------|
| GET /api/user/{id} | Go 先 | **6348** | 4452 | **+43%** |
| GET /api/note/{id} | Java 先 | **4801** | 4387 | **+9%** |
| GET /api/social/like/.../count | Go 先 | **5902** | 4697 | **+26%** |
| GET /api/social/comment/{id} | Java 先 | **6075** | 5110 | **+19%** |
| GET /api/notify/list | Go 先 | **5901** | 5571 | **+6%** |

### 延迟（Avg / Max）与 timeout

| 接口 | Go Avg | Go Max | Go timeout | Java Avg | Java Max | Java timeout |
|------|--------|--------|------------|----------|----------|--------------|
| 用户 | 7.68ms | **54.97ms** | 0 | 9.54ms | **48.43ms** | 96 |
| 笔记 | 8.82ms | **43.47ms** | 96 | 9.67ms | **45.53ms** | 96 |
| 赞数 | 8.22ms | **49.45ms** | 0 | 9.03ms | **44.53ms** | 95 |
| 评论 | 6.99ms | **36.99ms** | 96 | 8.31ms | **53.14ms** | 96 |
| 通知 | 7.21ms | **47.33ms** | 96 | 8.67ms | **42.15ms** | 0 |

五条吞吐均为 Go 更高。Avg 上 Go 也更低；Max 多数在 **37～55ms** 量级（本轮未测 P99）。

# Go vs Java 网关公平对比 20260910-120131

双端 **WSL 本机**；Go 使用 `bench/config/gateway-wsl-compare.yaml`（限流关、熔断关、无 Redis）；Java 为 `bench/java-gateway`（SCG，无限流）。

## 环境与压测参数（归档）

| 项 | 值 |
|----|-----|
| 宿主 | WSL2 |
| CPU（`nproc`） | **4** vCPU |
| 内存（`free`） | **~7.8 GiB** |
| 宿主 CPU 型号 | Intel Core i7-14650HX（WSL 配额 4 核） |
| wrk | **`-t4 -c50 -d20s`**（未加 `--latency`，无 P99） |
| 下游 | Docker `user-service` → `http://127.0.0.1:9001` |
| 路径 | `GET /api/user/{id}` |
| Go 鉴权 | JWT → 注入内部 HMAC |
| 直连鉴权 | `X-User-Id` + `X-Gateway-Ts` + `X-Gateway-Sign` |
| Java | `:8088`，无限流 |
| Go 配置 | `ratelimit.enabled=false`，`circuit_breaker.threshold=0`，redis 故意不可达 |

说明：默认 wrk 只给出 Latency **Avg / Stdev / Max** 与 **Socket timeout**；Max 为样本最大值，**不是** P99。

## 结果

| 场景 | Requests/sec | Latency Avg | Stdev | Max（尾部近似） | Socket timeout |
|------|--------------|-------------|-------|-----------------|----------------|
| 直连 + HMAC | **15880** | 3.10ms | 1.65ms | **43.84ms** | 0 |
| Go Gateway + JWT | **6119** | 6.95ms | 3.00ms | **53.95ms** | 93 |
| Spring Cloud Gateway + JWT | **5059** | 8.45ms | 4.17ms | **120.18ms** | 96 |

相对直连：Go ≈ 39%，Java ≈ 32%。Go 相对 Java 约 **+21%** QPS；尾部 Max 上 Go 也优于本轮 Java。

## 复现

```bash
docker compose -f deploy/docker-compose.yml -f bench/compose/docker-compose.bench.yml --env-file .env up -d
THREADS=4 CONNECTIONS=50 DURATION=20s ./bench/scripts/bench-gateway-fair.sh
# 若要 P99：在 wrk 命令上加 --latency
```


基于微服务架构的网关中间件系统(Golang) 
技术栈：Golang | Gin / MySQL | 反向代理 | Redis | JWT | 负载均衡 | 租户管理
(1)概述：实现了一个支持 HTTP/TCP/gRPC 三协议的反向代理网关，具备服务管理、租户鉴权、限流与流量统计功能，后端基于 Gin 框架，附带 Vue 管理界面，基于 iPanel 实现 docker 部署，基于后端 API实现大盘统计与 Admin 管理
(2) 代理功能：基于 httputil.ReverseProxy 实现 HTTP 反向代理，自实现随机、轮询、加权轮询、一致性 Hash 四种负载均衡策略，支持 URL 重写与 Header 修改。TCP/gRPC 分别基于标准库 net 与 grpc-proxy 实现透明转发
(3) 多租户鉴权：解析请求 Header 中的Bearer JWT，提取Issuer与内存租户列表匹配，作为独立中间件挂载在代理链上。基于 Redis 实现流量统计，令牌桶算法实现 QPS 与QPD 限制，客户端请求通过网关校验并路由至下游服务
(4) 动态服务注册：自定义实现下游服务器的动态注册/下线，动态更新负载均衡节点列表，为请求分配健康节点
(5) 网关中间件链：实现请求链路的中间件管理，包括权限认证/访问控制/流量统计与控制/服务熔断/黑白名单等环节
(6)性能：使用 wrk 压测，下游服务器(HTTP)直连QPS为9k， 经过代理 QPS 为6.5k，平均代理延时 53ms(4 核/12GB)
